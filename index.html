Three panels, one tutorial 🎬

No hand-written CSS selectors. The skill explores the live site, hardens the locators, and draws the PDF for you.

1

🕹️ Explore

A discovery subagent walks your task on the live site via the Playwright MCP server, reading each step from the accessibility tree.

2

🔒 Harden

Selector-hardening subagents pick the most robust locator per element — getByRole over fragile CSS — and checkpoint the spec one step at a time.

3

🖍️ Render

The renderer replays the spec in Chromium, screenshots each step, circles the target in red, adds a caption, and compiles a PDF.

Tutorials live as docs. 📚

The real deliverable isn't a throwaway recording — it's a replayable .spec.ts file. It's the single source of truth: commit it, diff it in PRs, resume it mid-flight, and re-verify it against the live site whenever the page drifts.

✓ Committable ✓ Resumable checkpoints ✓ Drift-checkable ✓ Plain Playwright 
// Tutorial: How to search on Wikipedia
// PDF output: wikipedia-search.pdf
import { test } from '@playwright/test';

test('How to search on Wikipedia', async ({ page }) => {
  await page.goto('https://www.wikipedia.org');

  // Step 1: Click the search box [verified]
  await page.getByRole('searchbox').click();

  // Step 2: Type your query [no-highlight]
  await page.getByRole('searchbox').fill('Playwright');
});

Re-run it: npx playwright test wikipedia-search.spec.ts

Install in one line 🚀

It's an Agent Skills package — a folder with a SKILL.md that works in Claude Code, Cursor, and VS Code Copilot.

1 · Copy the skill in

# into ~/.claude/skills (Claude Code & Cursor)
./install.sh claude

# also install deps + Playwright MCP
./install.sh claude --deps --mcp
# PowerShell
./install.ps1 claude

# also install deps + Playwright MCP
./install.ps1 claude -Deps -Mcp
⚠️ If scripts are blocked: powershell -ExecutionPolicy Bypass -File ./install.ps1 claude

2 · Set up the browser

Once, inside the skill folder (skipped if you passed --deps/--mcp):

npm install
npx playwright install chromium
🤖 You also need a Playwright MCP server so the skill can drive a live browser — --mcp wires it up automatically.

3 · Just ask 💬

Tell your agent: "generate a tutorial for how to search on Wikipedia." It writes tutorials/<slug>.spec.ts checkpoint-by-checkpoint, then renders the PDF right next to it.
